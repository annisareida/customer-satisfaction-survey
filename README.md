# Customer Satisfaction Survey - BPKARSS Web System

A web-based application designed to collect and manage customer satisfaction data for **Balai Pengelola Kereta Api Ringan Sumatera Selatan (BPKARSS)**. This project aims to digitize the feedback process to improve the service quality of Light Rail Transit (LRT) South Sumatra.

---

## 📌 Project Overview
This system provides a streamlined interface for passengers to fill out satisfaction surveys and a comprehensive dashboard for administrators to manage news, gallery content, and survey questions.

### Key Features:
* **Survey Management:** Multiple survey forms for different service categories.
* **Content Management System (CMS):** Full CRUD (Create, Read, Update, Delete) functionality for News (Berita), Gallery, and FAQs.
* **Admin Dashboard:** Centralized control panel for administrators to monitor data.
* **User Authentication:** Secure Login and Registration system for admin access.
* **Responsive Design:** Optimized for both desktop and mobile viewing.
